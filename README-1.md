# Escola Segura — Assédio Sexual nas Escolas

Website educativo académico, desenvolvido em HTML, CSS e JavaScript.

## Como visualizar
1. Extraia o ficheiro ZIP.
2. Abra a pasta `assédio_sexual_nas_escolas`.
3. Abra `index.html` num navegador (Chrome, Firefox, Edge, etc.).

## Como publicar gratuitamente no GitHub Pages
1. Entre em https://github.com e crie um repositório público.
2. Carregue os três ficheiros: `index.html`, `style.css` e `script.js`.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Seleccione a branch `main` e a pasta `/ (root)`, depois carregue em **Save**.
6. Aguarde a publicação. O GitHub apresentará o link do website nessa página.

## Conteúdo
O website inclui apresentação, introdução, definição e formas de assédio, factores associados, consequências, prevenção, recomendações por público, orientação para pedir ajuda, enquadramento moçambicano, conclusão, quiz e referências.

## Nota
O conteúdo é educativo e não substitui apoio profissional, aconselhamento jurídico ou os procedimentos oficiais de protecção. Em situações reais, a prioridade é a segurança e o encaminhamento para adultos de confiança e serviços competentes.
